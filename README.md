# 🏦 Banking Project

A Spring Boot–based banking application designed to demonstrate core backend concepts such as REST APIs, database integration, and secure configuration management.
Need to work on frontend of this application

---

## 🚀 Features
- User account creation and management
- Customer creation
- Balance inquiry and transaction history
- Fund transfer between accounts
- Secure authentication and authorization (Spring Security + JWT)
- External service integration (e.g., Twilio for SMS notifications) (Commented the sms service as twillio was just a trail account, you can enable it with another trail account)

---

## 🛠️ Tech Stack
- **Java 21**
- **Spring Boot**
- **Spring Data JPA**
- **PostgreSQL**
- **Maven**
- **Docker** (optional for containerization)
